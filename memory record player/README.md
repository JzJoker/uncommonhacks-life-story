# LifeStory

A memory journal app for people living with Alzheimer's and memory loss. Family and loved ones build a collaborative album — photos with voice narration — that patients can explore to rediscover their identity and relationships.

Built for [UncommonHacks](https://uncommonhacks.com) — competing in the **Social Impact** and **Best Use of ElevenLabs** tracks.

---

## How It Works

**Caregivers** create an account and set up a Life Story for their patient. They invite family and friends via SMS link.

**Contributors** (friends and family) sign in via SMS OTP, upload photos, and record narration for each memory. They can optionally upload audio samples of a deceased loved one for voice cloning.

**Patients** browse their memory journal. Tapping a photo plays the narration — a familiar voice introducing the people and moment in the image.

---

## Features

- **Photo + narration journal** — each memory entry is a photo paired with audio recorded or generated by family
- **ElevenLabs voice cloning** — clone the voice of a deceased loved one from uploaded audio samples; cloned voices narrate in third-person only (no first-person speech or invented content)
- **SMS OTP auth** — contributors join via invite link and sign in without a password
- **Experience modes** — self-paced (patient explores independently) or caregiver-guided
- **Q&A agent** — patients can ask questions about their memories; responses are spoken aloud

## Getting Started

### Prerequisites

- Node.js 18+
- A [Supabase](https://supabase.com) project
- An [ElevenLabs](https://elevenlabs.io) API key

### Installation

```bash
git clone https://github.com/your-org/uncommonhacks-life-story.git
cd uncommonhacks-life-story
npm install
```

### Environment Variables

Create a `.env.local` file at the project root:

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# ElevenLabs
ELEVENLABS_API_KEY=your_elevenlabs_api_key
ELEVENLABS_VOICE_ID=EXAVITQu4vr4xnSDxMaL
ELEVENLABS_MODEL_ID=eleven_turbo_v2_5

# Kimi (LLM for Q&A agent)
KIMI_API_KEY=your_kimi_api_key
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Design Principles

1. **Simplicity above all** — large tap targets, minimal text, calm colors; usable by someone with significant cognitive decline
2. **Voice authenticity** — familiar voices aid recognition and emotional regulation in dementia patients (research-backed)
3. **No hallucination** — narration only uses information explicitly provided by family; nothing is invented or inferred
4. **Third-person only for cloned voices** — avoids the ethical risk of making a deceased person appear to speak as themselves
5. **Emotional safety** — every content decision asks: *could this distress or confuse the patient?*

---

## Ethical Note on Voice Cloning

Voice cloning is deliberately constrained to **third-person factual narration**:

> *"This is your daughter Sara. She was born in 1985 and loves hiking."*

First-person speech (*"Hey honey, I miss you..."*) is never generated. This avoids puppeting a deceased person and reduces the risk of distressing or confusing the patient.
